# 로봇 프로젝트 메모 (예시)

## 음성 인식 연결
Whisper로 마이크 입력을 텍스트로 바꾸고, 미리 정한 명령어 목록과 비교해요. 인식 결과와 시간은 로그에 남겨요.

## Unity 관절 제어
Unity의 ArticulationBody로 관절 목표 각도를 설정해요. 명령어마다 목표 자세를 정의해요.

## ROS 2 통신
Unity와 ROS 2는 ROS-TCP-Connector로 연결하고, 관절 명령은 토픽으로 주고받아요.

## 정지 명령 처리
"정지" 명령은 다른 명령보다 우선해요. 인식되면 모든 관절의 목표 속도를 0으로 바꾸고, 대기 중인 명령 큐를 비워요.
